# Focus

تطبيق مهام ومشاريع وعادات وملاحظات مع تايمر بومودورو للتركيز — بالعربي، ويشتغل على الموبايل والآيباد والكمبيوتر.

**افتحه:** https://ismaeloo04.github.io/focus/

- أول مرة بتفتحه بيسألك شغلك إيه (طبيب، مدرّس، طالب، مهندس، مصمم، بيزنس، محامي، البيت…) ويجهزلك مشاريع بمراحلها وعادات تبدأ بيها.
- تقدر تختار اللون والشريط اللي فوق، والوضع الفاتح أو الغامق، من ⚙️ الإعدادات.
- بياناتك بتتحفظ على جهازك بس. لو عاوز تزامن بين أجهزتك، اعمل نسخة من `apps-script/Code.gs` على حساب جوجل بتاعك (الخطوات في أول الملف) وحط الرابط في الإعدادات ← المزامنة.
- **التثبيت:** آيفون/آيباد: Safari ← مشاركة ← Add to Home Screen. أندرويد: Chrome ← Install app. الكمبيوتر: أيقونة التثبيت في شريط العنوان.
